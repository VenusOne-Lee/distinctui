Black, white, grey. Then one mark that's yours.

A free design skill for Claude. Lots of white space, one typeface, black pill buttons, and a single signature colour you choose. It's the system behind Version One.

npx skills add VenusOne-Lee/distinctui

Or in Claude Code: /plugin marketplace add VenusOne-Lee/distinctui, then /plugin install distinctui.

Plain CSS, Tailwind v4, or SwiftUI for iPhone and iPad.

The CSS on its own, from npm

No Claude needed. The same classes, tokens, icons and motion, as the @distinctui/css package.

npm install @distinctui/css 
import "@distinctui/css";               // distinctui.css
import "@distinctui/css/distinctui.js"; // optional motion
// also: @distinctui/css/tailwind.css, /tokens.json, /icons.svg

Or from a CDN, with no build step:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@distinctui/css@0.2/skills/distinctui/assets/distinctui.css">
<script src="https://cdn.jsdelivr.net/npm/@distinctui/css@0.2/skills/distinctui/assets/distinctui.js" defer></script>

Twelve rules

  1. 1
    Light only. White background, black text. No dark mode, no dark sections.
  2. 2
    Black, white and four greys. No blue links, red errors, green ticks or gradients.
  3. 3
    Colour lives only on rings. One palette of five. If something else needs to stand out, use black, weight or space.
  4. 4
    One typeface. Bricolage Grotesque for everything. Monospace only for code.
  5. 5
    Light headings, one bold word. "Just shipped". Tight tracking.
  6. 6
    Main actions are black pills. The second action is outlined. The third is a text link.
  7. 7
    White space before borders, borders before shadows. The only shadow is on a floating menu.
  8. 8
    Pills for what you press, soft corners for what you read. Cards 22px, the feature card 28px.
  9. 9
    Dashed until live. The mark goes solid when the thing ships.
  10. 10
    Errors are black and bold. Name the field and the fix.
  11. 11
    Hover is a black edge, not a lift. No scale, no glow.
  12. 12
    Write plainly. Buttons say what happens. Sentence case. No "Oops".
