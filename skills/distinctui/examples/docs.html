Import your stock list

Already keep a list in Excel or Google Sheets? Bring it in once, then count by voice from there. About five minutes.

Get the file ready

Save your list as a CSV with these columns. The first row must be the column names. Extra columns are ignored.

ColumnWhat goes in itNeeded
nameWhat you call it at the counter, like White breadYes
countHow many you have nowYes
low_atWarn me when it drops to thisNo
priceSelling price in rand, like 18.50No
 
name,count,low_at,price
White bread,14,5,18.50
Maize meal 5kg,8,3,72.00
Airtime R10,40,10,10.00

Bring it in

  1. Open Spaza Stock and tap You, then Import a list.
  2. Pick the CSV file from your phone, Google Drive or WhatsApp.
  3. Check the preview. Rows with a problem are marked, with what to fix.
  4. Tap Import. Your items show up straight away.

Tip: Import doesn't delete anything. Items with the same name get the new count.

With the API

Sending the same list from your till or website? Post it to the items endpoint with your key from Settings → API keys.

curl https://api.spazastock.example/v1/items/import \
  -H "Authorization: Bearer $SPAZA_KEY" \
  -F "file=@stock.csv"
